Bảng bình chọn áp phích

—

⚙️ Cấu hình 1 lần trước khi dùng

  1. Mở Google Sheet chứa bảng kết quả đã tính điểm (2 cột: Tên áp phích | Tổng điểm).
  2. Trên tab đó: File → Share → Publish to web → chọn đúng tab → định dạng Comma-separated values (.csv) → Publish.
  3. Copy link CSV, mở file HTML này bằng trình soạn thảo, dán vào dòng const CSV_URL = "..." ở đầu phần script.
  4. Lưu lại và mở bằng trình duyệt (Chrome). Web tự làm phần còn lại.

Web chỉ đọc 2 cột kết quả — không đọc mã vote, không lộ dữ liệu gốc.
